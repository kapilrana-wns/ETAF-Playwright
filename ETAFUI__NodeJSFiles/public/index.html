Getting Started Guide — 5 minutes setup

1

Prerequisites

Ensure the following are installed on your system:

Java 21+
Maven 3.9+
Node.js 18+
Chrome / Firefox / Edge
Git (optional)
Terminal / CMD / PowerShell
2

Download the Framework

Download or clone the Enterprise Test Automation Framework (ETAF) repository from your source control. The package includes the core automation engine, sample test suites for OrangeHRM and SkillMatrix, the Node.js UI server, and all configuration files.

Download from SharePoint

3

Navigate to Project Root

Open your terminal and change to the project directory:

$ cd C:\Users\username\IdeaProjects\ETAF-NXG
4

Build the Project (First Time Only)

Run Maven to download dependencies and compile the project:

$ mvn clean install -DskipTests

This step downloads all Maven dependencies and compiles the Java source code. You only need to do this once, or when dependencies change.

5

Start the UI Server

Navigate to the Node.js files directory and start the server:

$ cd ETAFUI__NodeJSFiles
$ node server.js

You should see: Server is running on http://localhost:3000

6

Open the Dashboard

Open your web browser and navigate to:

> http://localhost:3000/

The 4-tab dashboard will load. You can now configure, execute, and review your test automation.

7

Configure Your Settings

The Config tab lets you manage all framework settings. Each section is collapsible — click a section header to expand it:

Feature Settings — toggles for mobile emulator, video recording, email, defect logging
General Settings — URLs, browser, viewport, screenshot preferences
Test Result — reporter type (Extent / Allure), output directories
Test Execution — local/remote/cloud mode, WebDriver timeout
Auto-Heal — self-healing engine config, retry counts
Database — DBMS connection settings for test data

Click Load Config to populate the form from test.properties, make changes, then click Save Configuration.

8

Run Tests

Switch to the Executer tab. Select a test suite, then click Run Tests:

All Tests — runs all suites from testng.xml
OrangeHRM — OrangeHRM login, landing page, navigation, auto-heal demo
SkillMatrix — Skills, SubCategory, MainCategory test suites
BDD / Cucumber — runs BDD scenarios (demo.feature) via testng-bdd.xml
Failed Tests Only — re-runs only the failed test cases from the last execution using testng-failedcases.xml (auto-generated)

Watch live console output as tests execute. The Stop button appears during execution to abort if needed. After completion, the report list auto-refreshes.

Tip: Running the OrangeHRM suite successfully validates that your entire setup — Java, Maven, browser drivers, framework configuration, and the UI server — is working end-to-end.

9

View Reports

Switch to the Report Viewer tab. The last 5 test runs appear as clickable buttons. Click any report to preview the Extent HTML report in the built-in viewer.

Reports are also available on disk at ./test_result/Result_<timestamp>/Result.html

10

Understanding Auto-Heal

The framework includes an AI-powered self-healing engine that automatically recovers from broken locators. During test execution:

  • When an element is not found, the engine tries alternate locator strategies (CSS, XPath fallbacks, tag-agnostic selectors)
  • Successful heals are logged in the console and Extent report with Warning status
  • Screenshots are captured at the moment of healing (if enabled)
  • A healing statistics summary is printed at JVM shutdown
  • The testscripts/OrangeHRM/OrangeHRMAutoHealDemoTest.java script demonstrates this with intentionally wrong locators

Support & Troubleshooting

Port 3000 in use

Change the port in server.js or kill the existing process with npx kill-port 3000.

Tests not found

Run mvn clean install -DskipTests first to compile. Check testng.xml for correct class paths.

Config not saving

Check that the server has write permissions to test.properties. Verify the file is not open in another editor.

Browser driver errors

WebDriverManager auto-resolves drivers. Ensure Chrome/Firefox is updated. For Firefox, set browser=FireFox in config.
